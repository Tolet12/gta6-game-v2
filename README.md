NEON PALMS v2 is an original open-world crime game set in Palmera Bay, a sun-soaked coastal city of palm-lined avenues, neon storefronts and a working beachfront, built with Three.js and running fully offline. You play a courier who takes hotter and hotter jobs — checkpoint runs, a hot package, cash drops, a getaway and a harbor finale — while a 0–5 star wanted system, police pursuits with roadblocks, traffic, pedestrians and a reputation ladder react around you.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
